Privacy by construction

One transaction. Four different views.

Canton sends each party only the contracts it is a stakeholder on. So every institution shares one correct record, and each sees only its own slice.

Pledgor

Its agreement, the live book, every call it's party to.

Never sees: the regulator's report.

Secured party

The same agreement and book, as the counterparty.

Never sees: the regulator's report.

Custodian

Everything operational. It settles every move and publishes the report.

Nothing hidden: it's the settlement agent.

Regulator

Only the audit report: coverage, positions, share of book, breaches.

Never sees: the agreement, the schedule, any call.

The regulator's node holds no agreement, no schedule and no call. No UI is hiding them: they were never shared with it. Tested: 0 raw contracts visible.
