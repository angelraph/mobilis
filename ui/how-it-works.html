How it works

The rulebook lives on the ledger.

Every movement is a Daml contract that passes the same checks when it is agreed, and again when it settles, against the book as it stands at that moment.

The lifecycle

Propose. Agree. Settle.

1

Propose

Either party proposes a delivery, substitution or return. The ledger values every asset from the agreed haircut and ignores whatever the browser sent.

2

Agree

The counterparty agrees, but only if the move keeps the book eligible, covered and inside its concentration limits. A bad move can't even be agreed.

3

Settle, atomically

The custodian settles. One asset out and one in, in a single transaction. The secured party is never unprotected for a moment.

The rulebook

Eight guarantees, enforced in Daml.

Eligible?

Rejects ineligible asset types before a move can be agreed.

Worth?

Computes value from the agreed haircut and ignores what the caller sends.

Covered?

Refuses any return or swap that would leave the book short of the margin requirement.

Concentrated?

Caps each asset type's share of the book.

Margin call met?

Can only be marked fulfilled when coverage is really there.

Book moved?

Settlement re-checks every rule against the book as it is at that moment.

Prices moved?

The custodian marks prices to market and the ledger re-values the whole book at once. A drop that leaves the book short blocks every release until the pledgor tops up.

Preview honest?

The browser's copy of the rules is held to the ledger's answers by 16 shared test cases run on both sides.

Each rule has a Daml Script test (20 in total) that proves it refuses what it should. See Valuation.daml and Tests.daml.

Collateral optimiser

AI that works inside hard rules.

"I need my Treasuries back for a repo." The optimiser finds the cheapest swap the agreement allows and explains why the tempting ones are illegal. The AI can only choose among rule-checked moves, and the ledger checks its choice again. The same engine proposes the cheapest top-up when prices fall, and which lots can go back when the book is over-covered.
