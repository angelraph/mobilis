Run it yourself

A real Canton ledger, on your machine.

This website runs on sample data, because a static host can't run a ledger. These steps start a real Canton ledger locally and connect the same interface to it, so every button runs a real Daml transaction. About 10 minutes the first time.

  1. Install the prerequisites (once)

    Git (git-scm.com; on Windows this also gives you Git Bash, which you use for every command below), Java 17 (adoptium.net) and the Daml SDK 2.10.6. On macOS or Linux:

    curl -sSL https://get.daml.com/ | sh -s 2.10.6

    On Windows, use the installer from docs.daml.com. Then open a new terminal and check:

    java -version
daml version

  2. Get the code

    git clone https://github.com/angelraph/mobilis.git
cd mobilis

  3. Run the tests optional

    cd daml
daml test
cd ..

    The setup scenario and all 14 tests should finish with ok.

  4. Start the ledger

    sh scripts/demo-ledger.sh

    It builds the Daml model, starts a Canton sandbox, creates the four parties with an empty agreement, and serves the interface. Wait for Demo ledger ready. Keep that terminal open, and press Ctrl+C in it to stop.

  5. Open the interface

    All four roles on one screen: http://localhost:7575/ui/demo-wall.html
    One role per tab: http://localhost:7575/ui/index.html?role=Pledgor (or SecuredParty, Custodian, Regulator).

  6. Walk through the demo

    1. Pledgor delivers UST-BILL, face 1000000: the ledger values it at 980,000. Secured party agrees, custodian settles.
    2. Secured party calls margin for 1400000; the custodian applies it. Coverage drops to 70%, and Mark fulfilled is refused.
    3. Pledgor delivers IG-CORP-BOND, face 500000. Agree and settle, and now the margin call can be fulfilled.
    4. Pledgor uses the Collateral optimiser ("Get back UST-BILL", then Suggest) and proposes the swap. Agree and settle.
    5. Pledgor proposes IG-CORP-BOND → CASH-USD, face 100. The secured party clicks Agree, and the ledger refuses it.
    6. Custodian generates the audit report. The regulator sees that report and nothing else.

Good to know

  • The AI features are optional. Without an API key, the optimiser uses its rules engine and everything still works. To turn the AI on: cd proxy, put OPENAI_API_KEY=… in .env, then run node server.js.
  • The first click after a fresh start can take up to 30 seconds while the ledger warms up.
  • daml: command not found? Open a new terminal. On Windows, use Git Bash.
  • Every start is a fresh, empty ledger. The full guide is in docs/RUN-LOCALLY.md.
