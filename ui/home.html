    How it works

    The rulebook lives on the ledger.

    Every movement is a Daml contract that passes the same four checks when it is agreed, and again when it settles, against the book as it stands at that moment.

    1

    Propose

    Either party proposes a delivery, substitution or return. The ledger values every asset from the agreed haircut and ignores whatever the browser sent.

    2

    Agree

    The counterparty agrees, but only if the move keeps the book eligible, covered and inside its concentration limits. A bad move can't even be agreed.

    3

    Settle, atomically

    The custodian settles. One asset out and one in, in a single transaction. The secured party is never unprotected for a moment.

    Privacy by construction

    One transaction. Four different views.

    Pledgor

    Its agreement, the live book, every call it's party to.

    Secured party

    The same agreement and book, as the counterparty.

    Custodian

    Everything operational. It settles every move.

    Regulator

    Only the audit report: coverage, positions, breaches.

    The regulator's node holds no agreement, no schedule and no call. No UI is hiding them: they were never shared with it. Tested: 0 raw contracts visible.

    Collateral optimiser

    AI that works inside hard rules.

    "I need my Treasuries back for a repo." The optimiser finds the cheapest swap the agreement allows and explains why the tempting ones are illegal. The AI can only choose among rule-checked moves, and the ledger checks its choice again.

    FAQ

    Questions judges ask.

    What is collateral, and what is "mobility"?

    When one institution lends to another, the borrower pledges assets (bonds, cash) as security. Values change daily, so the lender calls for more (a margin call), and the borrower often wants an asset back and offers a replacement (a substitution). Mobility means moving that collateral quickly and safely. Today it runs on spreadsheets and email.

    Is this really running on Canton?

    Yes. The rules are Daml smart contracts, and the demo video was recorded from a Canton sandbox through the real UI over the JSON API. The public preview uses sample data because a static host can't run a ledger. DevNet deployment is the next milestone.

    What does the AI actually do? Can it move assets?

    No, it can't move anything. The optimiser lists every swap the agreement's rules allow and scores each one by funding cost. The AI picks one of those and explains the choice. A person proposes it, the counterparty agrees and the custodian settles, and the ledger re-checks it at each step. With no AI available, the best-scoring valid move is used.

    How can the regulator see a report but not the book?

    Canton only sends a party the contracts it is a stakeholder on. The regulator is an observer on the audit report contract and nothing else, so its node never receives the agreement, the schedule or the calls. The tests query the ledger as the regulator and assert zero.

    What if the book changes after a swap is agreed?

    Settlement re-runs every rule against the book as it stands at that moment. If a margin call landed in between and the swap would now leave the book short, settlement is refused. That case has its own test.

    Who pays for this?

    Custodians and triparty agents. They carry the operational cost and the regulatory exposure today. The model is a platform fee per custodian plus a fee per active agreement, which we are validating in interviews.

    Why not a public blockchain, or a shared database?

    Collateral books are confidential, so a public chain exposes too much. A shared database needs one party everyone trusts to run it. Canton gives each party its own node, shares only what each is entitled to see, and settles multi-party moves atomically.

    What was built during the hackathon?

    A first version existed before the delivery phase and is tagged pre-hackathon-baseline in the repo. The on-ledger valuation, coverage, concentration limits, settlement re-check, margin-call lifecycle, optimiser, tests and this interface were built during it. The README lists everything.
